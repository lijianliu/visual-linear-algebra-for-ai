# Linear Algebra
* $\mathbb{ℝ}^n$ denotes an n-fold Cartesian product, or $\mathbb{ℝ}^n := \{(x_1, x_2, \ldots, x_n) \mid x_i \in \mathbb{ℝ}\}$. $\mathbb{ℝ}^n$ does not denote exponentiation (i.e., it does not mean ℝ to the n-th power).
* System of Linear Equations (线性方程组) In mathematics, a **system of linear equations** (or **linear system**) is a collection of two or more **linear equations** involving the same **variables**. For example,
    - $3x + 2y - z = 1$
    - $2x - 2y + 4z = -2$
    - $-x + \tfrac{1}{2}y - z = 0$

  This is a system of three equations in the three variables $x$, $y$, $z$. A **solution** to a linear system is an assignment of values to the variables such that all the equations are simultaneously satisfied. In the example above, a solution is given by the ordered triple $(x, y, z) = (1, -2, -2)$, since it makes all three equations valid.
